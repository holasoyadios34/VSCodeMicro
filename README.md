# VS Code Micro
vs code, but made in penguinmod!
The proyect can be found at: https://studio.penguinmod.com/#4523582460
If you will use the HTML, rename it to "index.html"
HTML packaged by Penguinmod packager (https://studio.penguinmod.com/PenguinMod-Packager )
Uses the OpenSource Ace Editor

Runtime
Mouse Cursor (by GarboMuffin)

Images

Proyect Interfaces (by Lord Cat)
Pang API
Text utilities (custom)
HTML (custom)
Ace Editor (custom)
Site Runtime (custom, https://raw.githubusercontent.com/Dinosaurmod/extensions/refs/heads/main/src/extensions/webextension.js )
